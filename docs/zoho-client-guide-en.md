# Zoho CRM Lead Handling Guide

This guide explains, in simple steps, how leads from the website should be used inside Zoho CRM.

It is written for day-to-day business use, not for developers.

## What Comes Into Zoho

When a visitor contacts you through the website, a new lead can be created in Zoho from:

- contact forms
- property inquiry forms
- request details actions
- book a viewing actions
- WhatsApp lead capture

Each lead can include useful context such as:

- visitor name
- email
- phone number
- inquiry type
- property title
- property link
- property ID / reference
- location / area
- price
- bedroom / bathroom count
- assigned agent
- message left by the visitor

## What The Team Should Do First

When a new lead arrives:

1. Open the lead record in Zoho.
2. Check the lead source and inquiry type.
3. Read the description carefully.
4. Review which property the person asked about.
5. Check which agent is assigned to that listing.

The description field is especially important because it usually contains the full website context.

## How To Read The Lead Quickly

Focus on these parts first:

- `Lead Name`
- `Email`
- `Phone` / `Mobile`
- `Lead Source`
- `Designation`
- `Website`
- `Description`

The `Description` usually tells you:

- how the lead came in
- which listing they asked about
- which page they were on
- whether they requested details, a viewing, or WhatsApp contact

## Recommended Workflow

### 1. New Website Lead

Use this when a lead first appears in Zoho.

Steps:

1. Confirm the contact details are valid.
2. Check the property link in the record.
3. Contact the lead as soon as possible.
4. Add a note after the first call, WhatsApp, or email.

### 2. Property Inquiry Lead

Use this when the lead is tied to a specific listing.

Steps:

1. Open the property link from the lead.
2. Review the price, area, and listing details.
3. Respond with the exact property information.
4. If the property is not available, offer similar listings.

### 3. WhatsApp Lead

Use this when the lead came through WhatsApp.

Steps:

1. Check which listing triggered the WhatsApp inquiry.
2. Review the user message in the description.
3. Respond through WhatsApp quickly.
4. Add follow-up notes inside Zoho.

### 4. Viewing Request

Use this when the lead wants to book a viewing.

Steps:

1. Check the requested property.
2. Review preferred date and time if included.
3. Confirm viewing availability.
4. Record the outcome in notes or activities.

## Best Practice For Sales Team

- respond quickly
- always review the property context before replying
- keep notes updated after every interaction
- move qualified leads through your internal sales process
- avoid leaving leads without an owner or follow-up

## Suggested Internal Rule

For every new website lead:

1. first response within the same day
2. add a note after first contact
3. mark status clearly
4. escalate hot leads immediately

## What To Do If A Lead Looks Incomplete

Sometimes a lead may arrive without every field filled in.

In that case:

- use the phone and email first
- read the description field
- check the property URL
- verify whether it came from WhatsApp, contact form, or property inquiry

## Simple Lead Checklist

Before closing or reassigning a lead, make sure:

- the customer was contacted
- the property was identified
- the assigned agent is clear
- notes were added
- next action is recorded

## Goal

The goal is simple:

- know who contacted you
- know from where they contacted you
- know which property they asked about
- respond quickly and clearly
